# GA4GH Refget Sequence Collections (seqcol) JSON Schemas

JSON Schema definitions for GA4GH Refget Sequence Collections v1.0.0,
mirrored from the [ga4gh/refget](https://github.com/ga4gh/refget)
specification repository (`docs/schemas/`).

| Schema | Description |
|--------|-------------|
| `seqcol_minimal_v1.0.0.json` | Minimal schema, describing only the 3 primary attributes (names, lengths, and sequences). |
| `seqcol_extended_v1.0.0.json` | Extended schema, describing all approved attributes. |
| `seqcol_refs_v1.0.0.json` | Minimal schema, using references. |

See the [Refget Sequence Collections spec](https://ga4gh.github.io/refget/seqcols/)
for the full specification. These files are mirrored here for
convenience; treat the upstream repository as the source of truth and
update if the upstream schemas change.
